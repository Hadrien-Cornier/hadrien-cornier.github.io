How to read this schematic

Each slab is a layer, each teal pair a layer's key/value cache. All 30 layers are shown. Ten numbered markers show denoising steps. A “read” means one action layer attending to cached video tokens, including all attention heads. It is not a memory transaction or a latency measurement.

Fusion uses learned softmax weights per attention head, shared between K and V. All lines here have equal width: learned weights are not visualized. One gold pair represents the full fused cache. Layer sizes, animation speed and token geometry are schematic. This is a comparison between separately trained architectures, not a checkpoint conversion.

Not drawn: the VAE, text encoder, text/state conditioning, action self-attention, feed-forward blocks and scheduler. Faster-WAM routes text/state through the video backbone only, and retracts video-key 3D RoPE into the action temporal basis before attention. The observed frame is at t = 0; inference here generates no future video.

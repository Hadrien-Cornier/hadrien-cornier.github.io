## Credit assignment

A reward often arrives long after the move that earned it. A value function, a number for the reward still to come from here, hands it back to the earlier moves. The return $G_t$ adds up the rewards from step $t$, each one counted by a factor $\gamma$ (the discount) more than the one before.

$$\begin{aligned} G_t = R_{t+1} &+ \gamma R_{t+2} \\ &+ \gamma^2 R_{t+3} + \cdots \end{aligned}$$

## The family tree

Each line names the failure of the method above that the method below repairs. It follows the family tree of [Breaking Bellman](https://hadrien-cornier.github.io/breaking-bellman/), a small game I made, in teaching order.

**Top half.** Trial and error leads to Monte Carlo, then Q-learning and n-step TD (parts 1 and 2).

**Bottom half.** Q-learning's failures lead to Sarsa, DQN and Double Q-learning (parts 3 to 5).

## One loop, one changing line

<div class="algo">
<div class="algo-title">The loop every method in the tree shares</div>
<ol>
<li>Pick a move a in the situation s (greedy, or random with probability ε).</li>
<li>Take it. Observe the reward r and the next situation s′.</li>
<li>Build a target for Q(s, a).</li>
<li>Q(s, a) ← Q(s, a) + α · (target − Q(s, a))</li>
</ol>
<div class="algo-note">The methods differ in line 3.</div>
</div>

<div class="ct">

| Method | Target (line 3) | Fails when |
| --- | --- | --- |
| [Monte Carlo](http://incompleteideas.net/book/RLbook2020.pdf) | $G_t$, the full return, after the episode ends | The episode is long or never ends |
| [Q-learning](https://www.gatsby.ucl.ac.uk/~dayan/papers/cjch.pdf) (part 1) | $r + \gamma \max_{a'} Q(s',a')$ | The table is too big, random tries cost falls, a max of noisy numbers runs high |
| [n-step TD](http://incompleteideas.net/book/RLbook2020.pdf) (part 2) | $R_{t+1} + \dots + \gamma^{n-1}R_{t+n} + \gamma^n V(S_{t+n})$ | Each row waits for $n$ rewards |
| [DQN](https://www.nature.com/articles/nature14236) (part 3) | Q-learning target, $Q$ is a network, old moves replayed, a frozen copy scores $s'$ | Numbers run high on some tasks, many samples needed, discrete moves only |
| [Sarsa](http://incompleteideas.net/book/RLbook2020.pdf) (part 4) | $r + \gamma Q(s',a')$, with $a'$ the move you take next | One random next move makes the target noisy |
| [Expected Sarsa](http://incompleteideas.net/book/RLbook2020.pdf) (part 4) | $r + \gamma \sum_{a'} \pi(a'\mid s')\,Q(s',a')$ | It needs every move's probability |
| [Double Q-learning](https://papers.nips.cc/paper/2010/hash/091d584fced301b442654dd8c23b3fc9-Abstract.html) | $r + \gamma\, Q_2\big(s', \arg\max_{a'} Q_1(s',a')\big)$ | Each table learns from half the updates |
| [Deadly triad](http://incompleteideas.net/book/RLbook2020.pdf) (part 5) | A formula, a guess as a target, old data | The numbers blow up |

</div>

## The bandit: one situation

The first branch has one situation, so the table has one row. The machines pay a hidden average plus noise.

$$Q(a) \leftarrow Q(a) + \tfrac{1}{n(a)}\bigl(r - Q(a)\bigr)$$

<div class="algo">
<div class="algo-title">Ten slot machines, 1,000 pulls (ε = 0 is the greedy robot, ε = 0.1 the other)</div>
<ol>
<li>Set Q(a) = 0 and n(a) = 0 for each machine a.</li>
<li>Repeat for 1,000 pulls:</li>
<li class="i1">With probability ε pick a random machine. Otherwise pick argmax Q(a), at random on a tie.</li>
<li class="i1">Pull it and observe the payout r. Set n(a) = n(a) + 1.</li>
<li class="i1">Q(a) ← Q(a) + (r − Q(a)) / n(a)</li>
</ol>
</div>

<div class="ct">

| Symbol | Meaning |
| --- | --- |
| $Q(a)$ | The number for machine $a$: the average payout so far |
| $r$ | The payout just received |
| $n(a)$ | Pulls of machine $a$ so far |

</div>

## Definitions

<div class="ct">

| Symbol | Meaning |
| --- | --- |
| $R_{t+1}$ | The reward after the move at step $t$ |
| $G_t$ | The return: later rewards added up, each one more factor of $\gamma$ |
| $\gamma$ | The discount, between 0 and 1 |
| $\pi$ | The policy: the rule that picks a move in each situation |
| $v_\pi(s)$, $q_\pi(s,a)$ | The return you expect from $s$, or after move $a$ in $s$, following $\pi$ |
| $v_*$, $q_*$ | The best of those over all policies |

</div>

<div class="eq-label">Average over a policy's moves</div>

$$v_\pi(s) = \sum_a \pi(a \mid s)\, q_\pi(s,a)$$

<div class="eq-label">Max over moves, for the best values</div>

$$\begin{aligned} v_*(s) &= \max_a q_*(s,a) \\ \pi_*(s) &= \arg\max_a q_*(s,a) \end{aligned}$$

<div class="rc-mark" id="sec-bellman1" data-panel="bellman" data-view="bellman1" data-title="Bellman: the return"></div>

## Where the Bellman equation comes from

I use the indexing of Sutton and Barto, so the equation numbers match their book.

<div class="eq-label">1. The return <span>Eq. 3.8</span></div>

$$\begin{aligned} G_t &= R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots \\ &= \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \end{aligned}$$

<div class="eq-label">2. Factor out $\gamma$ <span>Eq. 3.9</span></div>

$$\begin{aligned} G_t &= R_{t+1} + \gamma\bigl(R_{t+2} + \gamma R_{t+3} + \cdots\bigr) \\ &= R_{t+1} + \gamma\, G_{t+1} \end{aligned}$$

<div class="eq-label">3. The episode ends at step $T$: nothing is left</div>

$$G_T = 0$$

So the value of a terminal state is 0.

<div class="rc-mark" id="sec-bellman2" data-panel="bellman" data-view="bellman2" data-title="Bellman: average, then max"></div>

<div class="eq-label">4. Values are expected returns <span>Eq. 3.12 and 3.13</span></div>

$$\begin{aligned} v_\pi(s) &= \mathbb{E}_\pi\!\left[G_t \mid S_t = s\right] \\ q_\pi(s,a) &= \mathbb{E}_\pi\!\left[G_t \mid S_t = s,\, A_t = a\right] \end{aligned}$$

<div class="eq-label">5. Bellman equation for a policy <span>Eq. 3.14</span></div>

$$v_\pi(s) = \mathbb{E}_\pi\!\left[R_{t+1} + \gamma\, v_\pi(S_{t+1}) \mid S_t = s\right]$$

<div class="eq-label">6. Bellman optimality equation: the average becomes a max <span>Eq. 3.20</span></div>

$$\begin{aligned} q_*(s,a) = \mathbb{E}\Bigl[&R_{t+1} + \gamma \max_{a'} q_*(S_{t+1}, a') \\ &\Bigm| S_t = s,\, A_t = a\Bigr] \end{aligned}$$

<div class="ct">

| Symbol | Meaning |
| --- | --- |
| $S_t$, $A_t$ | The situation and the move at step $t$ |
| $\mathbb{E}_\pi[\cdot \mid S_t = s]$ | Average over the move $\pi$ picks and what the world does next |
| $a'$ | Any move in the next situation $S_{t+1}$ |

</div>

Equation 5 evaluates a policy you already have. Equation 6 defines the best one. The value is not a new reward: $R_{t+1}$ is real, and $\gamma\, v_\pi(S_{t+1})$ stands in for everything after it. Part 1 turns equation 6 into an update.

<summary>Sources and checks</summary>

Equation numbers are from Sutton and Barto, [*Reinforcement Learning: An Introduction*, second edition](http://incompleteideas.net/book/RLbook2020.pdf), checked in the published text.

- **Return.** Eq. 3.8 and 3.9. The recursion holds before the end of an episode if $G_T = 0$. The value of a terminal state is 0.
- **Values.** Eq. 3.12 and 3.13. Eq. 3.14 is written in expectation form, the first lines of the book's derivation. $v_\pi(s) = \sum_a \pi(a \mid s)\, q_\pi(s,a)$ is Exercise 3.12.
- **Best values.** Eq. 3.15 and 3.16. $v_*(s) = \max_a q_*(s,a)$ is in Section 3.6. Eq. 3.20 is the optimality equation for $q_*$.
- **One convention.** The book writes the reward for the move at step $t$ as $R_{t+1}$. I use that throughout. In part 1, $r$ and $s'$ stand for $R_{t+1}$ and $S_{t+1}$.
- **Family tree.** It follows the `tree` object in the game's `web/content.js` at commit 681cae3: 13 boxes, 14 lines. Two lines have an empty label in the game. "Waits for the end" and "DQN overestimates" are mine. Other trees in the game are left out.
- **Method table.** Targets are the standard definitions: Q-learning, Sarsa and Expected Sarsa in Sections 6.4 to 6.6, n-step TD in Chapter 7, Double Q-learning in van Hasselt 2010, DQN in Mnih et al. 2015. "Fails when" follows the game's method cards, which quote those sources. The triad is Section 11.3.
- **The first schematic.** The numbers are $0.9^k$, computed by hand. No run produced them.
